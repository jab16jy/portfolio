# Cuaderno de ingeniería

Identidad editorial: una firma compacta «JB.», folios numerados y un plano de capas construido con geometría vectorial propia. El dibujo de portada explica tres operaciones (especificar, implementar, verificar); no simula una interfaz ni representa un producto auditado. Los diagramas de los casos utilizan nodos reales del repositorio.

Papel cálido, tinta casi negra y un acento bermellón; en oscuro se invierten las superficies y se aclara el acento. Geist para lectura y Geist Mono para coordenadas, cifras y rótulos. Jerarquía mediante tamaño, espacio y líneas de división, no mediante una cuadrícula de tarjetas iguales. La experiencia y las competencias se leen como listas editoriales. Controles distinguibles con teclado, texto junto al color y un solo orden de lectura en móvil.
